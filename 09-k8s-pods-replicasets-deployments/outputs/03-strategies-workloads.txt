=== 5. TROUBLESHOOTING ===
--- 5a. SELECTOR MISMATCH ---

$ cat /Users/techsaswata/Downloads/devops-scaler/09-k8s-pods-replicasets-deployments/manifests/troubleshooting/selector-mismatch.yaml
# BROKEN ON PURPOSE: the selector says app=frontend but the pod template
# labels the pods app=frontend-app. The ReplicaSet can never find the pods it
# creates, so it creates them forever.
# The API server actually rejects this one - which is the lesson.
apiVersion: apps/v1
kind: ReplicaSet
metadata: { name: broken-selector }
spec:
  replicas: 2
  selector:
    matchLabels: { app: frontend }
  template:
    metadata:
      labels: { app: frontend-app }    # <-- does NOT match the selector
    spec:
      containers:
        - name: web
          image: nginx:1.27-alpine
$ kubectl apply -f selector-mismatch.yaml   (expected to FAIL)
The ReplicaSet "broken-selector" is invalid: spec.template.metadata.labels: Invalid value: {"app":"frontend-app"}: `selector` does not match template `labels`

>> The API server REJECTS it up front: `selector` does not match the
>> template labels. Without that validation the ReplicaSet would create
>> pods it could never recognise, and would keep creating them forever.
>> Fix: make spec.selector.matchLabels identical to the template labels.
