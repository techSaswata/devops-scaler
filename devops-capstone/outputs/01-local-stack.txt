=== 7. THE BOOKING CONFLICT IS A RACE, SO THE DATABASE SETTLES IT ===
slot: 2026-11-07T13:02:32+00:00

$ POST /api/appointments   doctor 1  (first booking)
  HTTP 201
$ POST /api/appointments   doctor 1, SAME instant, different patient
  {"detail":"that doctor already has an appointment at that time"}
  HTTP 409
$ POST /api/appointments   DIFFERENT doctor, same instant (must succeed)
  HTTP 201
$ POST /api/appointments   naive datetime, no timezone offset
  HTTP 422

>> 409 from a unique index, not from a pre-flight SELECT. Two concurrent
>> bookings can both pass an 'is it free?' check before either inserts, so
>> only the database can decide. 422 for the naive datetime: a clinic that
>> books across a DST boundary should not be guessing the timezone.
