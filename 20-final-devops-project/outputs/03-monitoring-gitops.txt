=== 8. CONTINUOUS RECONCILIATION - drift is corrected, not just detected ===
git declares replicas: 2. Scaling to 5 by hand is drift. selfHeal should
undo it without anyone asking.

$ kubectl scale deployment task-api -n finalproject-gitops --replicas=5
deployment.apps/task-api scaled

Sampling from t+0 so the correction is not missed between samples:
  t+0s   spec.replicas=5
  t+2s   spec.replicas=2
>> Reverted to 2 after ~2s. Argo CD won, as it should.

$ kubectl get deploy task-api -n finalproject-gitops
NAME       READY   UP-TO-DATE   AVAILABLE   AGE
task-api   2/2     2            2           12s

$ kubectl get application task-api -n argocd -o jsonpath='sync: {.status.sync.status}  health: {.status.health.status}{"\n"}'
sync: Synced  health: Healthy

>> The lesson: once GitOps owns a workload, kubectl is no longer a way to
>> change it. The only durable edit is a commit.
